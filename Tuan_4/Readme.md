Đây là Lab 4 sử dụng bộ dữ liệu Titanic nhằm thực hành các bước Data Cleansing và Feature Engineering trước khi xây dựng mô hình Machine Learning dự đoán khả năng sống sót (Survived) của hành khách.

Trong bài lab, thực hiện:

Đọc và kiểm tra dữ liệu từ file titanic_disaster.csv.

Phân tích dữ liệu thiếu (missing values) và trực quan hóa bằng heatmap.

Xử lý dữ liệu thiếu ở các cột như Age, Cabin, Embarked.

Tạo và biến đổi đặc trưng mới từ dữ liệu gốc.

Chuẩn bị dữ liệu cho bước xây dựng mô hình dự đoán.

Python

pandas: đọc và xử lý dữ liệu
